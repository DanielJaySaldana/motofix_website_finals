# MotoFix offline promotional website

This VS Code workspace contains the complete project from the supplied ZIP and a local XAMPP version at the workspace root.

## Start the site

1. Start **Apache** and **MySQL** in the XAMPP Control Panel.
2. If needed, import [`motofix-complete/database/motofix.sql`](motofix-complete/database/motofix.sql) in phpMyAdmin.
3. Open [http://localhost/motofix_website_finals/](http://localhost/motofix_website_finals/), or run `motofix-complete/Start MotoFix.bat`.

The feedback form saves submissions to `motofix_promotional.feedback_submissions`. The interactive demo also stores accounts, role-specific records, support tickets, and uploaded files in this MySQL database. Website artwork, fonts, video, styles, and demo code are stored in this workspace for offline use.
